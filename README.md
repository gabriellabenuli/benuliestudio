# 📊 Sistema Estúdio Benuli

Sistema de gestão completo para estúdios de design e agências criativas.

## 🚀 Features

- ✅ Dashboard com KPIs
- ✅ CRM de leads
- ✅ Gerenciamento de projetos
- ✅ Propostas e contratos
- ✅ Produção (templates)
- ✅ Biblioteca de recursos
- ✅ KPMO Kanban
- ✅ Tarefas e aprovações
- ✅ Financeiro
- ✅ Contador de horas

## 📱 Como usar

1. Abra o arquivo `index.html` no seu navegador
2. Ou acesse online em: [seu-dominio].vercel.app
3. Preencha suas informações em Configurações
4. Comece a usar!

## 💾 Dados

Seus dados ficam 100% no navegador. Faça backups regularmente em Configurações → Exportar.
